🥗 Calorie Tracker – React Application

📌 Overview:

The Calorie Tracker is a React-based web application that allows users to record the meals they ate along with the number of calories.
It automatically sums the total calories for the day and helps users understand their daily intake.

This project was created as part of a Web Development assignment.

🚀 Features:

Add meals with calorie values

Remove meals

Auto-calculate total daily calories

Simple and responsive UI

Multi-page navigation using React Router

Clean component structure

🛠️ Technologies Used:

React JS

React Router DOM

CSS (or Tailwind, depending on your project)
